# Автодеплой — минимальная настройка

Тебе не нужно трогать workflow. Я уже добавил его в:
`.github/workflows/deploy.yml`

Осталось сделать только 5 вещей:

1. Создать репозиторий на GitHub и загрузить туда этот проект.
2. Создать SSH-ключ для деплоя:
   `ssh-keygen -t ed25519 -C "deploy-ignitechat" -f %USERPROFILE%\.ssh\ignitechat_deploy`
3. Добавить ПУБЛИЧНЫЙ ключ (`ignitechat_deploy.pub`) на сервер в:
   `/root/.ssh/authorized_keys`
4. В GitHub → Settings → Secrets and variables → Actions создать секреты:
   - SERVER_HOST = 82.202.169.146
   - SERVER_PORT = 22
   - SERVER_USER = root
   - SERVER_SSH_KEY = содержимое приватного файла `ignitechat_deploy`
5. Сделать push в ветку `main`.

После этого каждый `git push` будет автоматически обновлять сайт.
